# Akışlar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Depoda tanımlı akışları (agent, script, gate adımları) bir görevin worktree'sinde adım adım yürüten, insan kapılarını Kararlar sayfasının Bekleyen sekmesinde soran motor ve ekran.

**Architecture:** Motor kokpit sunucusunun içinde çalışır ve `server/lib/flows/` altındaki dosyalara bölünür:

| Dosya | Görev |
|---|---|
| `parse.js` | Akış dosyasını ayrıştırır ve doğrular |
| `store.js` | SQLite tabloları `flow_runs`, `flow_steps`, `flow_script_approvals` |
| `agents.js` | Ajan bağdaştırıcıları |
| `runner.js` | Yürütücü |
| `gates.js` | Kapılar ve Decision üretimi |

HTTP katmanı `server/routes/flows.js`. Ajan adımlarında Claude Code mevcut `run-spawner`'ın başsız moduyla, GLM ise `opencode run` ile çalışır. Kapılar `Decision` olarak üretilir ve `listDecisions` sonucuna eklenir. Ekran Task 7'de, onaylı taslaktan sonra.

**Tech Stack:** Node (node:test), better-sqlite3, js-yaml 4.3.1 (zaten bağımlılık), React + i18n (6 dil), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-16-akislar-design.md`

## Global Constraints

- Yeni bağımlılık yok. YAML için `require("js-yaml").load(text)`, varsayılan güvenli şema.
- Motor kendisi hiçbir zaman push etmez, PR ya da issue yazmaz.
- `script` adımları depo + komut bazında ilk çalıştırmada onaylanır. Onay `flow_script_approvals` tablosunda tutulur.
- Arayüz metinleri 6 dilde (tr, en, vi, zh, ko, es).
- Testler gerçek `~/.claude`, gerçek veritabanı ya da gerçek `claude`/`opencode` ikililerine dokunmaz. Ajan bağdaştırıcısı testte sahte bir nesneyle değiştirilir.
- Hata mesajları Türkçe.

## Kararlar (17 Kasım, kontrolcü)

- **Ajanlar v1:** `claude` ve `opencode`. `codex` ve `cursor` ayrıştırıcıda "henüz desteklenmiyor" hatası verir.
- **Dosya yeri:** adım girdi ve çıktıları worktree içinde `.ai-cockpit/run/` altında durur. Önceki turun çıktısı `<ad>.tur<N>.md` olarak saklanır.
- **İnceleme sonucu:** `basarisizsa` alanı olan adımın çıktı dosyasının ilk satırı `SONUÇ: TAMAM` ya da `SONUÇ: DÜZELT` olmalıdır.
  - `DÜZELT` gelirse ve o adımın tur sayısı `en_cok_tur`'dan küçükse akış `basarisizsa` hedefine (her zaman önceki bir adım) döner ve oradan sırayla devam eder.
  - Tur sınırı dolmuşsa adım kapı olur: mesaj "Tur sınırı aşıldı", seçenekler Onayla ya da Geri gönder.
  - İlk satır ikisi de değilse adım `failed` olur.
- **Sunucu yeniden başlarsa:** `running` durumdaki adımlar `interrupted` olur, akış `interrupted` olur ve açılışta o adımdan kendiliğinden sürdürülür. Aynı adım iki kez başlamaz.
- **Görev başına tek koşu:** aynı `cwd` için `running` ya da `gate` durumunda bir koşu varken ikinci başlatma 409 döner.

## Review Focus

1. Sunucu akış ortasında yeniden başlarsa çalışan adım "kesildi" olur, akış o adımdan sürdürülür ve aynı adım iki kez başlamaz. Test: Task 3 `resume after restart`.
2. Kapıdan geri gönderilen adımın önceki çıktısı saklanır ve adım yeni tur numarası alır. `en_cok_tur` aşılınca akış kapıda durur. Test: Task 3 `round limit stops at gate`, Task 4 `send back keeps previous output`.
3. Ajan sıfır kodla çıkar ama beklenen `cikti` dosyası yoksa adım hata olur. Test: Task 3 `missing output fails step`.
4. Aynı görevde iki akış başlatılırsa ikincisi reddedilir. Test: Task 4 `second start is 409`.
5. Maliyet tavanı aşılırsa yürütücü yeni adım başlatmaz ve akış kapıda durur. Test: Task 3 `cost cap stops at gate`.

### Task 1: Ayrıştırıcı ve doğrulama (est:2h)

**Files:**

**Interfaces:**
- Produces: `parseFlow(text: string) -> Flow`. Hatada `Error` fırlatır, `err.code = "EFLOW"`.
- `Flow = { ad, aciklama, maliyet_tavani?: number, adimlar: Step[] }`
- `Step` ortak alanları: `id`, `tur: "agent"|"script"|"gate"`.
- `agent` adımı:
  - `rol` (yol), `ajan: "claude"|"opencode"`, `model?`, `girdi: string[]`, `cikti?`;
  - `basarisizsa?`, `en_cok_tur` (varsayılan 2), `zaman_asimi_dk` (varsayılan 60).
- `script` adımı: `komut`, `zaman_asimi_dk` (varsayılan 10).
- `gate` adımı: `gosterilen: string[]`, `geri_gonderilebilir: string[]`, `mesaj?`.

- [ ] **Step 1: Başarısız testler**
  - `parses a valid flow`: spec'teki örnekle aynı biçimde, ama `ajan: claude`/`opencode` olan bir akış hatasız ayrışır. Varsayılanlar doludur, `girdi` dizi olur.
  - Hata testleri. Her biri belirtilen alan adını içeren Türkçe mesaj vermeli:
    - `rejects unknown step type`: `tur: foo` -> mesajda `adimlar[1].tur`.
    - `rejects missing fields`:
      - `agent` adımında `rol` yok;
      - `script` adımında `komut` yok.
    - `rejects duplicate ids`.
    - `rejects unknown or forward targets`:
      - `basarisizsa` ve `geri_gonderilebilir` yalnız var olan ve kendinden önceki adımları gösterebilir.
    - `rejects input with no producer`: `girdi: [x.md]`, ama önceki hiçbir adımın `cikti` değeri `x.md` değil.
    - `rejects unsupported agent`: `ajan: codex` -> "henüz desteklenmiyor".
    - `rejects path escape`: `rol`, `cikti` ya da `girdi` içinde `..` ya da mutlak yol.
    - `rejects bad yaml with line`: YAML hatasında mesaj satır numarasını içerir (js-yaml `err.mark.line + 1`).
    - `en_cok_tur bounds`: 1..5 dışı hata.

### Task 2: Durum deposu (est:2h)

**Files:**
- Modify: `server/db.js` (yeni tablolar, mevcut `CREATE TABLE IF NOT EXISTS` bloklarının yanına)
- Create: `server/lib/flows/store.js`
- Test: `server/__tests__/flows-store.test.js` (geçici DB, `api-errors.test.js` başlığıyla)

**Tablolar:**
```sql
CREATE TABLE IF NOT EXISTS flow_runs (
  id TEXT PRIMARY KEY, repo TEXT NOT NULL, cwd TEXT NOT NULL, task TEXT, flow TEXT NOT NULL,
  flow_json TEXT NOT NULL, status TEXT NOT NULL, current_step TEXT, gate_note TEXT,
  cost_usd REAL NOT NULL DEFAULT 0, cost_cap_usd REAL,
  started_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')), ended_at TEXT);
CREATE INDEX IF NOT EXISTS idx_flow_runs_cwd ON flow_runs(cwd, status);
CREATE TABLE IF NOT EXISTS flow_steps (
  id INTEGER PRIMARY KEY AUTOINCREMENT, run_id TEXT NOT NULL, step TEXT NOT NULL, round INTEGER NOT NULL,
  status TEXT NOT NULL, exit_code INTEGER, session_id TEXT, log_path TEXT, note TEXT,
  cost_usd REAL NOT NULL DEFAULT 0, started_at TEXT, ended_at TEXT,
  FOREIGN KEY (run_id) REFERENCES flow_runs(id) ON DELETE CASCADE);
CREATE INDEX IF NOT EXISTS idx_flow_steps_run ON flow_steps(run_id, id);
CREATE TABLE IF NOT EXISTS flow_script_approvals (
  repo TEXT NOT NULL, command TEXT NOT NULL, approved_at TEXT NOT NULL, PRIMARY KEY (repo, command));
```
- Run durumları: `running`, `gate`, `done`, `failed`, `stopped`, `interrupted`.
- Step durumları: `running`, `done`, `failed`, `gate`, `interrupted`, `stopped`.

**Interfaces (hepsi `db` ilk parametre, senkron):**
- `createRun(db, {repo, cwd, task, flow}) -> run`. `flow` ayrışmış Flow nesnesidir: `flow_json` içine yazılır, `flow` sütununa `flow.ad`, `cost_cap_usd` sütununa `flow.maliyet_tavani` girer.
- `getRun(db, id)` döner: `{...run, flow: Flow, steps: StepRow[]}`, ya da `null`.
- `listRuns(db, {repo?, cwd?, status?})` en yeniden eskiye sıralı döner.
- `activeRunForCwd(db, cwd)`: durumu `running` ya da `gate` olan koşuyu, yoksa `null` döner.
- `setRun(db, id, patch)`.
- `startStep(db, runId, step, status = "running") -> row`. `round`, aynı adımın önceki satır sayısı + 1 olur.
- `finishStep(db, rowId, patch)`.
- `lastStep(db, runId, step)`.
- `roundsOf(db, runId, step) -> number`.
- `addCost(db, runId, rowId, usd)`: adıma ve koşuya ekler.
- `markInterrupted(db) -> string[]`: `running` adımları `interrupted` yapar, koşularını da `interrupted` yapar, etkilenen run id'lerini döner.
- `isScriptApproved(db, repo, command)`, `approveScript(db, repo, command)`.

### Task 3: Yürütücü ve ajan bağdaştırıcıları (est:5h)

**Files:**
- Create: `server/lib/flows/agents.js`, `server/lib/flows/runner.js`
- Test: `server/__tests__/flows-runner.test.js`

**Interfaces:**
- `agents.js`:
  - `runAgent({ajan, model, prompt, cwd, logPath, timeoutMs}) -> {promise: Promise<{exitCode, sessionId|null}>, kill()}`.
    - `claude`: `require("../run-spawner").spawnRun({prompt, mode: "headless", cwd, model, permissionMode: "acceptEdits"})`. Sonra `getRun(id)` her 2 saniyede bir yoklanır; durum `completed`, `error` ya da `killed` olunca biter. `sessionId` handle'dan alınır. Zaman aşımında ve `kill()`'de `killRun`.
    - `opencode`: `child_process.spawn("opencode", ["run", "--dir", cwd, "-m", model, "--agent", "build", "--dangerously-skip-permissions", prompt], {cwd})`. stdout ve stderr `logPath`'e yazılır. `sessionId` null olur.
  - `runScript({komut, cwd, logPath, timeoutMs}) -> {promise: Promise<{exitCode}>, kill()}`: `spawn(komut, {shell: true, cwd})`, çıktı `logPath`'e yazılır.
  - `sessionCostUsd(db, sessionId) -> number`: `token_usage` satırları ve `require("../../routes/pricing").calculateCost` ile hesaplanır. Pricing satırlarını mevcut rotanın yükleme biçimiyle oku. Bulunamazsa 0.
- `runner.js`: `createRunner({db, agents = require("./agents")}) -> { start(runId) -> Promise, resumeAll() -> Promise, onGateAnswered(runId) -> Promise, stop(runId) }`. Testte `agents` sahte nesneyle verilir.
  - Döngü:
    - koşu `running` iken sıradaki adımı belirle;
    - adımı çalıştır;
    - sonuca göre bir sonraki adıma, `basarisizsa` hedefine ya da kapıya geç;
    - bütün adımlar `done` ise koşu `done`.
  - Sıradaki adım: koşunun `current_step` değeri, yoksa ilk adım.
  - Agent adımının istemi, şu bölümlerin sırayla birleştirilmesidir:
    1. Rol dosyasının içeriği (`cwd`'ye göreli).
    2. `## Görev` ve `.ai-cockpit/brief.md` (varsa).
    3. Her girdi için `## Girdi: <ad>` ve `.ai-cockpit/run/<ad>` içeriği.
    4. Koşunun `gate_note` değeri (varsa) `## Kapı notu` altında. Kullanıldıktan sonra temizlenir.
    5. Son satır: `Çıktını .ai-cockpit/run/<cikti> dosyasına yaz.` (`cikti` varsa). `basarisizsa` alanı varsa ek olarak: `İlk satır "SONUÇ: TAMAM" ya da "SONUÇ: DÜZELT" olsun.`
  - Çıktı turu: adım yeniden çalışmadan önce mevcut `.ai-cockpit/run/<cikti>` dosyası `<ad>.tur<N>.md` olarak yeniden adlandırılır. `N` önceki turdur.
  - `logPath`: `.ai-cockpit/run/log/<adım>-<tur>.log`.
  - Maliyet: her agent adımından sonra `sessionCostUsd` eklenir. Bir adım başlamadan önce `cost_usd >= cost_cap_usd` ise o adım kapı olur: not "Maliyet tavanı aşıldı".
  - Script adımı: `isScriptApproved` değilse adım kapı olur (`note: "Script onayı: <komut>"`). Kapı onaylanınca Task 4 `approveScript` çağırır ve aynı adım yeniden çalışır.
  - Gate adımı: adım satırı `gate` olur, koşu `gate` olur, döngü durur. Kapı cevabını Task 4 işler ve `onGateAnswered(runId)` döngüyü yeniden başlatır.
  - `resumeAll()`: `markInterrupted(db)` döndürdüğü koşular için, `interrupted` adımdan yeni tur başlatır ve koşu `running` olur.

- [ ] **Step 1: Başarısız testler.** Geçici git dizini ve geçici DB kullanılır. `agents` sahte nesnesi her çağrıyı kaydeder ve `cikti` dosyasını istenen içerikle yazar.

### Task 4: Kapılar, Kararlar bağlantısı ve API (est:3h)

**Files:**
- Create: `server/lib/flows/gates.js`, `server/routes/flows.js`
- Modify:
  - `server/lib/decisions.js`: `listDecisions` sonucuna `flowDecisions(db, {project})` eklenir.
  - `server/index.js`: `/api/flows` rotası kaydedilir; sunucu açılışında `runner.resumeAll()` çağrılır.
- Test: `server/__tests__/flows-route.test.js`

**Interfaces:**
- `flowDecisions(db, {project?}) -> Decision[]`: kapı olmuş her adım satırı için bir Decision.
  - Alanlar:
    - `id: "flow:<runId>:<step>:<round>"`, `agent: "cockpit"`, `reason: "confirmation"`;
    - `header`: akış adı;
    - `message`: adımın `mesaj` alanı ya da durum notu, yoksa "Kabul bekleniyor";
    - `askedAt` adımın `started_at` değeri, `project` koşunun repo'su, `sessionId: ""`, `selected: []`, `other: false`.
  - `metadata: {kind: "gate", runId, step, shown: [dosya yolları], sendBack: [adım id'leri]}`.
  - Durum: satır `gate` ise `pending`, `done` ise `resolved` (`payload: {answer: "approve"|"send_back", note}`, adım `note` sütunundan), `stopped` ise `cancelled`.
- `answerGate(db, runner, runId, {action: "approve"} | {action: "send_back", step, note})`:
  - `approve`:
    - Kapı adımı `done` olur.
    - Script onayıysa `approveScript` çağrılır; `current_step` script adımında kalır.
    - Tur sınırı ya da maliyet kapısıysa sıradaki adıma geçilir.
    - `onGateAnswered` çağrılır.
  - `send_back`:
    - `step` değeri, kapı adımının `geri_gonderilebilir` listesinde (tur sınırı kapısında `basarisizsa` hedefi) olmalı; değilse 400.
    - Not, koşunun `gate_note` sütununa yazılır.
    - `current_step` hedef adım olur ve `onGateAnswered` çağrılır.
- Rotalar (hatalar `wrap` deseninde, 500'de genel mesaj):
  - `GET /api/flows?repo=` -> `{runs}`.
  - `GET /api/flows/:id` -> `{run}` (adımlarla).
  - `POST /api/flows` `{cwd, flow: "<ad>", task?}`:
    - `cwd` bir git checkout olmalı (`checkoutRoot`).
    - `<cwd>/.ai-cockpit/akislar/<ad>.yaml` okunur ve `parseFlow` ile ayrıştırılır; `<ad>` yalnız `[a-z0-9-]`.
    - Aynı `cwd`'de etkin koşu varsa 409.
    - `repo` değeri `workRepo(cwd)` olur. Koşu oluşturulur, `runner.start` beklenmeden çağrılır, 201 `{run}` döner.
  - `POST /api/flows/:id/gate` -> `answerGate`.
  - `POST /api/flows/:id/retry`: son `failed` ya da `interrupted` adımdan yeni tur başlatır.
  - `POST /api/flows/:id/restart` `{step}`: `current_step` o adım olur; o adımdan yeni tur başlar, sonraki adımlar yeniden koşar.
  - `POST /api/flows/:id/stop`: `runner.stop` çağrılır; çalışan süreç durdurulur, koşu ve adım `stopped` olur.
  - `GET /api/flows/:id/file?path=`: yalnız koşu `cwd`'sinin `.ai-cockpit/run/` altındaki dosyaları. `realpath` kontrolü yapılır; dosya düz metin olarak döner.

- [ ] **Step 1: Başarısız testler** (createApp, geçici DB, geçici git dizini). Sahte `agents`'ı enjekte etmek için `server/routes/flows.js` bir test kancası dışa açar: `router.__setRunner(createRunner({db, agents}))`.
  - `second start is 409`.
  - `gate appears in decisions pending`: `/api/decisions?project=` bekleyen listesinde `metadata.kind === "gate"` olan bir kayıt görünür.
  - `approve finishes run`.
  - `send back keeps previous output`: `send_back` -> hedef adım tur 2, önceki çıktı `.tur1.md`, not istemde.
  - `send back to non-allowed step is 400`.
  - `stop marks stopped`.
  - `file endpoint rejects paths outside run dir`.
